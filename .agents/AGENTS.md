# AGENTS.md - Workspace Rules

## UI & Design Guidelines

### No Unnecessary Border Divider Lines Rule
- NEVER add extra horizontal or vertical border lines (`border-t`, `border-b`, `border-[#E2E8F0]`, `border-slate-200`, `<hr />`) above bottom action buttons, under titles, or between form/modal content sections.
- Always rely on clean whitespace padding (`space-y`, `gap`) rather than border lines.
